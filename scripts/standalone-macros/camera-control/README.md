# About
Control the camera using the keyboard.

Key-W: Move forward

Key-S: Move backward

Key-A: Move left

Key-D: Move right

Key-E: Move up

Key-Q: Move down

Arrow-Key-Left: Rotate left

Arrow-Key-Right: Rotate right

Arrow-Key-Up: Rotate up

Arrow-Key-Down: Rotate down

# Installation
Add a link to the script in the macros directory of FreeCAD.

```
# FreeCAD version 1.0.X:
cd ~/.local/share/FreeCAD/Macro

# FreeCAD version 1.1.X:
cd ~/.local/share/FreeCAD/v1-1/Macro

ln -rs path/to/git/repository/scripts/camera_control.py
```
