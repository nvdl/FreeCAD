# About
Control the camera using the keyboard.

Key-W: Move forward

Key-S: Move backward

Key-A: Move left

Key-D: Move right

Key-E: Move up

Key-Q: Move down

Camera rotation is not supported yet.

# Installation
Add a link to the script in the macros directory of FreeCAD.

```
cd ~/.local/share/FreeCAD/Macro
ln -rs path/to/git/repository/scripts/camera_control.py
```
