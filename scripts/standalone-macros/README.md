# About
Macros that can be executed using assigned toolbar buttons.

# Installation
Add links to the scripts in the macros directory of FreeCAD.

```
# FreeCAD version 1.0.X:
cd ~/.local/share/FreeCAD/Macro

# FreeCAD version 1.1.X:
cd ~/.local/share/FreeCAD/v1-1/Macro

ln -rs path/to/git/repository/scripts/script.py
```
